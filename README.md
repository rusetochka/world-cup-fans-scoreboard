# World Cup Fans Scoreboard

A static demo of a World Cup prediction scoreboard. The participant profiles and predictions are fictional. The demo uses a fixed set of match fixtures.

Open **Try your own prediction**, pick a fan and a match, and choose an outcome to see scores recalculate. Prediction overrides are saved in your browser. Reset restores the fictional starting predictions.

Run `npm test` to check the scoring and demo behavior, or `npm start` to run the demo locally.
